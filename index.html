I'm a Software Engineer at Celloscope Ltd, where I build Java backend services for Agrani Bank PLC and the Microcredit Regulatory Authority, including internet banking, agent banking, national ID verification and SMS alerting.

Most of my work sits where security and integration meet: biometric login on Keycloak, Redis-backed one-time verification, data masking, and connecting to core banking (Temenos T24), Bangla QR and ekPay. I care about clean code, solid tests and systems that stay up on release day.
